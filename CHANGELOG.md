# Changelog

## [2.0.0] - 2026-10-28
### Added
- Dynamic product grid with category filter, search and sorting
- Cart drawer with quantity controls and persistent storage
- Wishlist, dark mode, newsletter validation, toasts, back-to-top
- 4 new products (lilac hoodie, long skirt, jumpsuit and more)
- Free-shipping progress bar and NK10 coupon code in the cart
- Announcement bar, discount badges, active nav link and nav shadow on scroll
- SEO/Open Graph meta tags, README, LICENSE, .gitignore

### Changed
- Redesigned CSS using variables, CSS grid and a proper mobile menu
- Images converted to WebP with descriptive names (12 MB → under 1 MB)
- Buttons are real links/buttons with keyboard focus styles
- Font updated to Poppins
- Logo-only brand (text removed); logo inverts automatically in dark mode
- One single brand pink (#e48c9a) used everywhere, dark text on pink for contrast

### Fixed
- Wrong image used for the "Lyocell resort shirt" (it showed the dress)
- Invalid markup (stray closing tags, misused `<Address>`)
- Empty alt text and fixed-width layouts breaking on small screens
- Credit bar no longer overlaps the page content
